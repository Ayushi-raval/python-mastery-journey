## What is Python?

Python is a high-level, interpreted, dynamically typed programming language.
It supports both object-oriented and functional programming styles.

Python is popular because it is:

- Simple and easy to learn
- Open-source
- Platform-independent
- Supported by a large library ecosystem
- Useful for web development, data analysis, AI/ML, automation, and databases

## Installation

1. Download Python from the official website: https://www.python.org/
2. Install it for your operating system.
3. Verify the installation:

```bash
python --version
```

4. Install packages using `pip`:

```bash
pip install pandas
```

## Getting Started

Create a file named `hello.py`:

```python
print("Hello World !!!")
```

Run it:

```bash
python hello.py
```

Output:

```text
Hello World !!!
```

## Python Syntax

Syntax means the rules for writing valid Python code.
Python uses indentation to define blocks of code.

```python
for i in range(5):
    print(i)
```

## Comments

Comments are ignored by Python and are used to explain code.

```python
# This is a single-line comment
print("Hello, Python!")
```

## Variables

Variables store data. Python automatically detects the data type.

```python
name = "Aayushi"
age = 20
is_learning = True
```
